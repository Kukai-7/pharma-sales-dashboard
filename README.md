# Asia Markets Dashboard

Group project, *Financial Data Visualization* course, MSc Data & Corporate Finance (Audencia, Paris).

A full pipeline from raw financial data to an interactive Power BI dashboard, presented live in Power BI (no slides allowed).

## What it does

- **ETL** in Power Query: import, clean and reshape raw market data
- **Data model** and DAX measures in Power BI
- **Focus on Asia**, benchmarked against Europe and the Americas
- One question per page, not one chart per metric

## Stack

`Power BI` `Power Query` `DAX`
